Amadda 문제 관리 API 테스트

문제 생성, 조회, 사용자 답변 수정 및 문제 삭제 API를 테스트합니다.

공통 설정

사용자 ID, 과목 ID, 위키 문서 ID는 해당 API에서 사용하는 실제 식별자를 입력하세요.

1. 문제 생성

POST /problems/create

위 JSON은 입력 예시입니다. 실제 필드명과 값은 problem_generator.generate_problem()에서 요구하는 형식에 맞게 수정하세요. 

아직 요청하지 않았습니다.

2. 문제 생성 진행 상태 확인

POST /problems/is-creating 

아직 요청하지 않았습니다.

3. 전체 문제 조회

POST /problems/get-all 

아직 요청하지 않았습니다.

4. 전체 사용자 답변 조회

POST /problems/get-all-user-answers 

아직 요청하지 않았습니다.

5. 사용자 답변 수정

PATCH /problems/user-answers/update

수정할 필드는 실제 사용자 답변 데이터 구조에 맞게 입력하세요. 

아직 요청하지 않았습니다.

6. 문제 삭제

DELETE /problems/delete

문제 삭제는 실제 데이터에 영향을 줄 수 있습니다. 삭제할 문제 ID를 확인하세요. 

아직 요청하지 않았습니다.
